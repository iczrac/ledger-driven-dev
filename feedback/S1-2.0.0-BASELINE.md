## 四、根因与修复契约（S3 依据）

生成器 `build()` 两处拼接（module code 第 566 行、cap code 第 596 行）：
```
mnode["code"] = f"{code}.{mcode}"              # <ROOT> + <PROJ>.DATA → <ROOT>.<PROJ>.DATA
cap_code      = f"{code}.{mcode}.{domain}.{seq}"# → <ROOT>.<PROJ>.DATA.READY.01（5 段）
```
单项目模板契约是 `project.code=DEMO` + `module.code=DATA`（不含项目段）→ 4 段正确；
主仓 monorepo 契约是 `project.code=<ROOT>` + `module.code=<PROJ>.DATA`（已含项目段）→ 5 段错误。

**修复**：引入 `code_namespace(project_code, module_code)`：若 `module_code` 首段已是项目码
（含 `.` 且首段大写项目码），直接用 `module_code` 作命名空间；否则 `project_code.module_code`。
- 主仓 `<PROJ>.DATA` → namespace `<PROJ>.DATA` → cap `<PROJ>.DATA.READY.01`（4 段）✓
- 模板 `DATA` → namespace `DEMO.DATA` → cap `DEMO.DATA.READY.01`（4 段）✓（双写兼容）
- `no_regress()` 随之可用同格式 code 直接比对，不再靠前缀剥离对齐。
