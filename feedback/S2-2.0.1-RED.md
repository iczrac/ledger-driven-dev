## 二、红灯实测：验收契约


结果：`overall=fail`。L7 四项：

| id | status | errors |
|---|---|---|
| `registry_schema_doc` | pass | `[]` |
| `registry_schema_test` | pass | `[]` |

前两项 pass 是正确的：规格文档与专项测试先写，符合 TDD；真正需要产品实现的后两项必须红。

## 三、红灯实测：专项测试

命令：

```text
python3 -m unittest discover -s tests/core -p test_registry_schema.py -t tests -v
```

结果：7 项全部未通过。

- `test_schema_name_is_registry_2`：ERROR，缺 `templates/registry_codec.py`；
- `test_dual_read_produces_identical_caps`：ERROR，缺 codec；
- `test_normalize_projects_exposes_project_config`：ERROR，缺 codec；
- `test_stable_code_keeps_explicit_identity`：ERROR，缺 codec；
- `test_generator_consumes_shared_codec`：FAIL，生成器未消费共享 codec；
- `test_verify_ledger_consumes_shared_codec`：FAIL，校验器未消费共享 codec；
- `test_trace_common_has_no_bare_five_segment_code`：FAIL，仍有裸拼五段码。

这正是上一阶段风险清单中的两个核心破坏点：**容器双读缺口**与**第二套 codec**。
