# 32 · 本地 D3 可视化：离线交互，不造第二事实源

v2.12.0 把 D3 v7.9.0 作为**本地静态文件**引入看板。D3 只负责把账本已有的派生投影画成
可交互的树/网格/折线；数据仍由 `build_capability_model.py` 在 Python 侧算好并内嵌到
`index.html`，前端不下载、不写回、不需要后端。

## 1. 本地文件与引入

- 权威源：`templates/vendor/d3.v7.min.js`（sha256 `f2094bbf6141b359722c4fe454eb6c4b0f0e42cc10cc7af921fc158fceb86539`）
- 项目副本：`<project>/governance/vendor/d3.v7.min.js`，由 `scripts/upgrade.py` 的 `TOOLING` 下发。
- 模板引用：`<script src="vendor/d3.v7.min.js"></script>`，纯相对路径，`file://` 直接可用。
- 不变量：`file_layout.py` 登记该文件；`check.sh` 比对权威源与 demo 副本逐字节一致。

**更新方法**：只替换 `templates/vendor/d3.v7.min.js` → 更新本文件 sha256 → 提高方法版本 →
由 `upgrade.py apply --approved-by <人>` 推到项目。禁止在项目目录里手改 D3 或改 CDN 链接。

## 2. 哪些视图用了 D3

| 视图 | D3 用法 | 降级路径 |
|---|---|---|
| `heatmap` 能力成熟度热力图 | `scaleOrdinal` 色阶 + 分组网格；键盘/鼠标可选中能力点并钻取证据 | 原生 CSS grid + `.heat-cell` |
| `trend` 成熟度趋势 | `scaleLinear` / `axisLeft` / `axisBottom` / `line`；点悬停放大、点击钻取 | 原生手拼 SVG |
| `lineage` 追溯链（新增） | `hierarchy` + `tree` + `linkHorizontal`；决策节点可展开/收合，叶节点显示证据路径 | `<details>` 嵌套树 |

`queue` 卡片墙、健康度条等简单视图保持原生 DOM，避免为了用库而用库。

## 3. 数据契约（Python 预计算）

`analytics` 保持 `maturity-analytics/1`，新增两个子投影：

- `analytics.timeline[]`：`{seq, ts, type, note, fingerprint, change_count, codes}`，趋势图横轴摘要，不复制 `state_digest`。
- `analytics.lineage`：`trace-lineage/1`，`trees[code]` 是 `d3.hierarchy()` 可直接消费的树：
  `capability → decision → evidence → state`。每组证据上限 6 条，状态节点等于当前 level/tier/completion。

第 29 条不变量 `analytics_d3_projection_valid` 校验：schema、节点 id 唯一、kind 合法、
决策引用真实、状态节点等于当前能力、时间轴 seq 递增。旧账本无 `lineage` 判 `na`；
前端 `deriveLineage()` 在内存补齐，仍不写盘。

## 4. 离线、What-if 与降级

- `hasD3()` 检查 `d3.select / scaleLinear / hierarchy`；任一缺失，三个视图全部回退原生实现。
- What-if 只操作 `VIEW_DATA` 深拷贝；会同步趋势末点、追溯状态节点、变更高亮信号。
- `DATA`（内嵌账本）从不改动；退出模拟即恢复原对象。
- 无 CDN、无 fetch 依赖、无后端服务：断网 `file://` 打开即可交互。
